# 🧭 Pathfinding Visualizer in C++

A console-based **Pathfinding Visualizer** built with **C++** that demonstrates how different pathfinding algorithms explore a grid and find a path from a start node to a destination node.

The project provides an interactive terminal interface where users can create obstacles, generate random mazes, assign random weights, and visualize each algorithm step-by-step. It is designed as an educational project to better understand graph traversal and shortest path algorithms.

## 📚 Algorithms Implemented

### 🔹 Breadth-First Search (BFS)
- Explores nodes level by level.
- Guarantees the shortest path in an unweighted grid.

### 🔹 Depth-First Search (DFS)
- Explores nodes deeply before backtracking.
- Useful for traversal but does not always produce the shortest path.

### 🔹 Dijkstra's Algorithm
- Finds the shortest path based on path cost.
- Supports weighted grids.
- Guarantees the optimal shortest path.
